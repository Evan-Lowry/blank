# unmarked.

unmarked. turns a shareable Crowdmark results link into a blank assessment PDF. It also runs a searchable Waterloo Assessment Bank. Use this checkout as the project root and start by checking `git status --short --branch`.

## Current product behavior

- The home page (`#home`, the default) is a hero that says only "Search for a course" over a large search box, with "or paste a Crowdmark link" under it, browse-by-course chips, and recently added exams (`GET /api/bank/summary`). The same search form moves from the header into the hero on home. The converter lives at `#converter` and starts centered. Each assessment has its own input. A paste can fill several inputs, but only distinct, valid `https://app.crowdmark.com/score/<uuid>` links are accepted from the pasted text. An invalid paste leaves existing inputs intact.
- **Prepare PDF** generates the blank PDF, checks for a duplicate, and immediately publishes a new file in the public assessment bank. It opens the first successful preview in the split view. The converter stays on the left. Show **Download all** above the results once the batch has at least two successful PDFs. It downloads those PDFs in one ZIP with distinct filenames.
- The assessment bank is public without sign-in. `#exam-bank` is a plain list of courses (Course, Exams, Latest term) from `GET /api/bank/courses`, filtered by the search box. A course page (`#exam-bank/MATH137`, or `#exam-bank/unknown` for entries with no detected course) is a list of that course's exams (Term, Type, Pages), newest term first, with a Type filter and **Download all**. Each row has Preview and Download buttons and a three-dot menu (Copy link, Report a problem). Previews open in the same split view. Course list, exam list and the home page's recently added list share one `.list` style and narrow-width rules. The current release made the previous pending submissions public. Keep previously rejected entries excluded. Submissions have no approval step.
- The server detects course, term, assessment type, and optional number from the fetched booklet path, and fills in what is still missing from Crowdmark's course name (for example "STAT 230 - Fall 2026") and the assessment title, which the page sends in its `template` (Crowdmark blocks the Worker from reading results itself). A hidden (`pending`) copy of the same PDF is published when a later conversion recognises it; removed (`rejected`) copies stay removed. Contributors have no classification selector. **Only assessments whose course, term, and type are all recognised are added to the public bank.** Anything else is stored hidden (status `pending`) so the person who converted still gets a preview and download, and the row says it was not added to the bank. Every public list also hides entries with no course. To loosen the rule, change the `recognised` check in `saveExam` (`worker/exam-bank.js`).
- Use the browser’s built-in PDF viewer in an iframe for all previews. The same generated PDF displayed in desktop Safari when served from a direct same-site URL, while the embedded `blob:` URL left the pane blank. Keep the inline HTTP route, and keep the preview pane free of a second download button.

- Layout follows UW Flow and MathSoc (header search, hero landing page, flat lists with quiet row buttons; header and pages share one 68rem container) in a dark-only black/gray/white palette. There is no light theme. The accent is Electric blue (`#3d8bff`). The page background is a aurora glow (three colours) with faint contour lines faded in from the top, drawn by `body::before` and `body::after`; the colours are the `--aurora-1`, `--aurora-2` and `--contour` variables. The glow layers are absolutely positioned at the top of the page and drift at half speed as you scroll (`--scroll-y`, skipped under reduced motion). The list header row and list rows are transparent, so the background shows through; only the viewer, menus and dialogs are solid. Colors are variables at the top of `web/index.html`; `--accent` drives primary buttons, focus rings, and the selected-row bar. The brand is the lowercase wordmark "unmarked." with the period in the accent blue and a matching blue-dot favicon. The header has Convert and Assessments links, and the wordmark returns to the home page. Restrained copy.
- A small footer (Home, About, GitHub) sits at the bottom of every page, and `#about` is a short About page (what blank. does, what is and is not stored, public-bank notice, not affiliated with Waterloo or Crowdmark). There is no Email link yet because the owner has not chosen a public address; do not publish the owner's personal or university address without asking.
- **Paste anywhere:** pasting a shareable Crowdmark link into the search box or onto the page (outside any other input) opens `#converter` with the link filled in and focus on Prepare PDF. It never starts converting by itself, because converting publishes to the public bank. The same prefill is reachable at `#convert=<url-encoded link>` (the bookmark on the About page uses it). The link stays in the `#` part, so it is never sent to a server, and the page replaces it with `#converter` straight away. The bookmark works from a `/score/<uuid>` page (one link) or inside the signed-in Crowdmark student area, where it reads `/api/v2/student/assignments` in the user's own tab and sends the `score-uuid` links for the course page being viewed (course pages only, never all courses) to `#convert=`, space-separated. It never starts converting.
- **Lists:** there is no star. Each row's three-dot menu has **Add to list…**, which shows your lists with ticks (tick as many as you like) and **+ New list**. A small blue dot beside a row's type means it is in at least one of your lists. The **Lists** nav link (`#lists`) shows your lists, `#lists/<id>` opens one (Copy share link, Download all, and a three-dot menu with Rename and Delete list), and **New list** creates one and drops you into naming it. Lists live in `localStorage` (`blank-lists`: up to 20 lists of 60 assessments) with no accounts. A share link is `#list=<ids>&name=<name>`, which anyone can open read-only and copy with **Add to my lists**. Starred items from the first version are migrated into a list called Saved. `GET /api/bank/exams?ids=...` returns up to 60 approved assessments.
- **Sync (no accounts):** the **Sync** button on the Lists page turns on sync, which creates a private 16-character code (`XXXX-XXXX-XXXX-XXXX`) and keeps one saved copy of the browser's lists in `sync_profiles` (D1, migration `0005`). Only a SHA-256 hash of the code is stored, and the code travels in the `X-Sync-Code` header of `/api/sync` (POST creates, GET reads, PUT saves with `baseVersion` and returns 409 plus the latest copy on a conflict, DELETE turns it off), so it never appears in a URL. Another device connects by entering the code. The client merges by list id and unions assessments, so syncing never loses anything. It syncs on page load, when the tab becomes visible, and about 1.5 seconds after any list change. Turning sync off on one device deletes the saved copy and the other devices turn themselves off on their next sync, keeping their lists. New codes are capped by `MAX_DAILY_SYNC_PROFILES` (default 500). Only list names and assessment ids are synced, nothing else.
- Brand: the product was called blank. and is now **unmarked.** (chosen over other options; the unmarked.ca domain looked unregistered when checked, and no similar exam tool was found). Internal names deliberately still say `blank`: the Worker, D1 database, R2 bucket, GitHub repository, the `blank.crowdmark.workers.dev` address and the `blank-*` localStorage keys. Changing the web address or localStorage keys loses people's lists and sync code, because browsers keep them per address.
- Naming: the public name is the **Assessment Bank** (nav link: **Assessments**) because it holds tests, quizzes, midterms, finals and assignments, not only exams. URLs, routes, table names and filenames keep the older `exam-bank` / `exam` names so shared links and the database keep working.

## Source map and data flow

| Path | Responsibility |
| --- | --- |
| `web/index.html` | HTML, CSS, converter form, batch processing, ZIP download, shared native preview |
| `web/exam-bank.js` | Exam bank navigation, search, filters, listing |
| `worker/index.js` | Worker entrypoint, origin checks, request routing, Crowdmark export |
| `worker/exam-bank.js` | Metadata detection, storage, deduplication, lists, PDF responses |
| `worker/pdf.js` | Generates a PDF using JPEG pages and records their byte offsets |
| `worker/guard.js` | Per-IP rate limits and Turnstile verification for the public write endpoints |
| `scripts/build.mjs` | Builds the Worker (`dist/server/index.js`): the page, its assets and the server code in one file |
| `wrangler.jsonc`, `DEPLOY.md` | Cloudflare configuration (bindings, limits, public settings) and the setup and admin guide |
| `drizzle/` | D1 schema and migrations. Update `meta/_journal.json` when adding a migration. |

- `POST /api/export` retrieves Crowdmark's original exam-master booklet pages, then sanitizes and assembles the JPEGs. It cannot recover missing booklet pages. It publishes only the reconstructed blank copy and basic exam metadata. Keep original Crowdmark results links, grades, and student work out of stored or public records.
- The exporter returns the PDF for download and, when `nativePreview` is requested, `X-PDF-Preview` pointing to a two-hour inline PDF URL. The older `submitForReview` request field is a compatibility flag. Its name predates direct publishing. Published bank entries use `GET /api/bank/pdf/<id>?view=1` for previews. Omit `view=1` to download the file.
- The worker uses D1 (`DB`) and R2 (`BUCKET`). D1 stores metadata, deduplication hashes, and preview tokens. R2 holds the rebuilt PDF. SHA-256 checks identical PDF bytes, including compatible older entries without a hash. Preserve deduplication across simultaneous requests. Two visually similar PDFs may have different bytes.
- `GET /api/bank/exams` lists public entries (filters: `course`, `exact`, `year`, `season`, `assessment`). `POST /api/bank/report` stores a problem report in `exam_reports` (reasons: `student-work`, `wrong-details`, `other`). Reports never hide an entry by themselves. The owner reads them with `npm run reports` (see `DEPLOY.md`).
- **Copy link** (`#exam-bank/<COURSE>/<id>` opens that course and auto-previews the exam) and **Report** live in each row's three-dot menu. **Download all** (ZIP, up to 60 exams) is on the course page. The header search lists recent courses from `localStorage` when focused and empty, and `/` focuses it.
- The frontend uses plain browser JavaScript. The build inlines `web/exam-bank.js` into the HTML and bundles `fflate` as a same-origin asset. The assessment bank has no upload path; entries come only from Crowdmark conversion. `fflate` creates batch ZIP files in the browser. Edit the sources above and regenerate the output directories.

## Local development and checks

```sh
npm ci
npm run db:local   # once: applies the migrations to a local D1 (answer y)
npm run dev        # builds, then runs the Worker locally at http://localhost:8787
```

`npm run dev` runs the built Worker under Cloudflare's own local runtime (`wrangler dev --local`), the same one production uses. Its D1 and R2 live in the git-ignored `.wrangler/` folder, so it never touches live data, and the local bank starts empty. For write tests, add synthetic assessments with `npx wrangler r2 object put blank-assessments/exams/<id>.pdf --file x.pdf --local` and `npx wrangler d1 execute blank --local --command "INSERT INTO exam_bank ..."`. Turnstile is skipped locally (no `TURNSTILE_SECRET`). Try the rate limits with lowered values: `npm run build && npx wrangler dev --local --var RATE_REPORT_PER_HOUR:3`. Set `WRANGLER_SEND_METRICS=false` to turn off Wrangler's telemetry.

Useful checks are `node --check web/exam-bank.js`, `node --check dist/server/index.js`, and `git diff --check`. Smoke-test invalid and multi-link paste, immediate public listing for a fresh PDF, exact duplicates, native Safari preview, and ZIP download with two successful results. Use synthetic files for writes. The live assessment list and existing public PDFs are safe read-only smoke checks.

## Hosting and publishing

- **Cloudflare (free plan) is the only host.** `wrangler.jsonc` binds `DB` (D1, `drizzle/` as migrations) and `BUCKET` (R2 `blank-assessments`) and holds the public settings; `DEPLOY.md` has the setup and admin guide. Live at https://blank.crowdmark.workers.dev (workers.dev subdomain `crowdmark`, D1 `blank`, R2 `blank-assessments`). Ship with `npm run db:remote` (new migrations) then `npm run deploy`. ChatGPT Sites and GitHub Pages were retired and removed from the code; do not reintroduce them, CORS for another origin, or their login headers.
- **Free-plan guard:** `checkPublishLimits` in `worker/exam-bank.js` pauses publishing at `MAX_STORED_PAGES` or `MAX_DAILY_PUBLISHES` from `wrangler.jsonc`, and new sync codes are capped by `MAX_DAILY_SYNC_PROFILES`.
- **Abuse guards (`worker/guard.js`):** `/api/export`, `/api/bank/report` and `POST /api/sync` are rate limited per IP per hour (60 / 10 / 5, `RATE_*_PER_HOUR` in `wrangler.jsonc`) using the D1 table `rate_limits` (migration `0006`, keyed hash of `CF-Connecting-IP`, answers 429 with `Retry-After`). The Workers Rate Limiting binding was not used because it only allows 10 or 60 second periods. Prepare PDF and Report can also verify a Cloudflare Turnstile token on the server; it is skipped when `TURNSTILE_SECRET` is unset, and it is **currently off** in production (empty `TURNSTILE_SITE_KEY`, no secret) because the human-check prompt annoyed users. See `DEPLOY.md` to turn it on. The site key (`TURNSTILE_SITE_KEY`) is injected into the page by the Worker, and the CSP allows `challenges.cloudflare.com` only when it is set. Writes are accepted only when the `Origin` header equals the site's own origin. Setup is in `DEPLOY.md`.
- **Admin:** there are no accounts or editor screens. Read problem reports with `npm run reports`, and hide or remove an assessment with the `wrangler d1 execute` and `wrangler r2 object delete` commands in `DEPLOY.md`.
- **Source remote:** `origin` is the public repository [Evan-Lowry/blank](https://github.com/Evan-Lowry/blank) (`main`), the only GitHub repository for this project. The old `clean-copy` repository (it held only the retired GitHub Pages build) was deleted. Everything pushed here is public, so keep secrets, real Crowdmark links and personal addresses out of commits. Local-only files stay untracked through `.gitignore` (`.wrangler/`, `.local/`, `.env*`, `.dev.vars*`, `dist/`, `node_modules/`, `.claude/settings.local.json`).
- Keep access tokens and runtime secrets out of source and handoff files. Secrets are set with `npx wrangler secret put NAME`. Never use someone's real Crowdmark results URL for a write test unless they explicitly want that assessment to be published.
